## 2024-05-18 - Reduce TLS Handshakes for External Translators
**Learning:** The application instantiates a new `requests` connection or OpenAI client on every translation request for DeepL and OpenAI backends. Since translation often occurs in a loop (many text boxes in a comic) and within background worker threads that manage their own event loops, doing a full TLS handshake for each request creates significant latency. Using connection pooling (like `requests.Session()`) and reusing synchronous client instances prevents these repeated handshakes and measurably speeds up batch translation.
**Action:** Always reuse HTTP connection pools (e.g., `requests.Session()`) or client instances when making repeated external API calls, especially in processing loops or batch operations.
