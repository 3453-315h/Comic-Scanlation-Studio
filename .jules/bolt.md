## 2025-02-20 - Avoid full-image operations inside loops
**Learning:** In the `Inpainter` module, iterating over multiple bounding boxes and using `cv2.bitwise_or` on full-size image arrays (e.g., 3000x2000 pixels) causes O(N * W * H) operations, which becomes a major bottleneck for pages with many text bubbles (e.g., 50+ bboxes per page). The runtime scaled linearly with the number of bounding boxes multiplied by the total image pixels.
**Action:** When combining region-specific masks or images, always extract or return just the Region of Interest (ROI) and apply it to the main array using NumPy slicing (e.g., `combined_mask[y1:y2, x1:x2] = cv2.bitwise_or(combined_mask[y1:y2, x1:x2], roi_mask)`). This changes the complexity to O(sum of ROI areas), which is orders of magnitude faster.
