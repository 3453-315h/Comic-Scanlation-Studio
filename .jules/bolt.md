## 2024-10-22 - Network Connection Pooling
**Learning:** External API calls (e.g. DeepL, OpenAI) in the translator module are making new TCP connections (including TLS handshakes) for every single translation request because they use module-level `requests.post()` and dynamically instantiated `OpenAI()` clients. This causes a massive performance bottleneck during batch processing.
**Action:** Use `requests.Session()` and cache the `OpenAI` client instance on the `Translator` class to reuse connections and improve translation performance. When doing so, mock tests to patch `requests.Session.post` instead of `requests.post` or `requests.get` if needed, although it seems tests mostly patch `requests.get` for other parts, or maybe I should check `test_finding_6_translation_failures.py`.
