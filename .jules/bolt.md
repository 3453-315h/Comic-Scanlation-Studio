## 2024-05-24 - Add Connection Pooling for Translators
**Learning:** External API calls (DeepL, OpenAI) in `Translator` lack connection pooling, making repeated TLS handshakes for each text bubble, causing bottlenecks in batch processing. The `requests.post()` is used in `_deepl_translate` and `OpenAI()` creates a new client per translation in `_openai_translate`.
**Action:** Always reuse HTTP clients or use `requests.Session()` across translations to prevent repeated TCP/TLS handshakes and speed up processing. Ensure that `Translator` handles `requests.Session()` correctly but avoiding sharing `OpenAI` client if threads are an issue (Wait, OpenAI handles connection pooling internally via `httpx` and `httpx.Client`, but instantiating `OpenAI()` each time still reconstructs the client. `requests.Session()` should be used for DeepL).
