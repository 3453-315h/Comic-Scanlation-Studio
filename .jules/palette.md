## 2026-08-18 - Accessibility & UX in PySide6\n**Learning:** In PySide6, ARIA labels are achieved through `setAccessibleName()` and visual interaction affordances like hover state pointers require setting the cursor shape explicitly via `setCursor(Qt.CursorShape.PointingHandCursor)` on widgets like `QPushButton` and `QCheckBox`.\n**Action:** Apply `setAccessibleName()` to all icon-only buttons and set the cursor shape to a pointing hand on clickable UI elements for consistent micro-UX in Qt applications.
