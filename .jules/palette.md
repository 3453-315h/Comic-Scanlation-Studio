## 2024-08-28 - PySide6 Widget Accessibility and Hover State Learnings
**Learning:** In PySide6 desktop applications, Qt widgets require explicit configuration to match standard web accessibility and interaction expectations. Standard push buttons (QPushButton) and checkboxes (QCheckBox) do not display a "pointer" hand cursor on hover by default, and buttons relying on emojis or single letters (like "B" for Bold, or "➕ New Project") lack proper screen reader labels.
**Action:** Next time working with PySide6/PyQt UI components, proactively apply `setAccessibleName()` to icon/emoji buttons for screen readers, `setToolTip()` for visual clarity on abbreviated buttons, and `setCursor(Qt.CursorShape.PointingHandCursor)` on all primary interactive elements to provide instant visual feedback on hover.
